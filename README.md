# 全自定义功能插件 (`koishi-plugin-fully-customized-function-mywl`)

> [插件由 AI 生成] 可视化「磁贴」任务编排插件：将 **OneBot v11 全部内置接口**、**Koishi 运行状态与自定义命令**、代码工具 / **数据库 / 文件操作** / 网络请求（GET / POST）磁贴自由组合为自动化任务流程，在 Koishi 控制台 WebUI 中拖拽编排、保存后按条件自动执行，并带完整执行日志面板。

---

## 功能特性

- **WebUI 入口**：仅管理员（通过 auth 插件登录、权限 ≥ 3）可在控制台左侧看到并访问「全自定义功能」入口
- **磁贴库（45 个 OneBot 接口磁贴 + 系统磁贴 + 工具磁贴）**：发送/撤回消息、踢人、禁言、全体禁言、设群名片/群名/头衔、群公告精华、好友点赞、入群/好友请求处理、群信息/成员查询、群文件、OCR、运行状态等；系统磁贴覆盖 **Koishi 状态 / 机器人状态**（返回 JSON）、**JSON / XML / 随机数 / 时间日期 / 字符串 / 数组** 代码工具、**网络请求 GET / POST**、**数据库读写**、**文件与文件夹操作**、**注册/触发自定义命令**、**AI 对话请求**
- **数据库操作**：对已注册数据表执行 查询 / 插入 / 更新 / 删除，支持条件 JSON 与查询条数限制（如本插件的 `mywl_ftask`、`mywl_flog`）
- **文件操作**：写入（覆盖/追加）/ 读取 / 删除文件，创建 / 删除文件夹，列出目录；路径限制在插件数据目录 / Koishi 数据目录 / 临时目录内，禁止 `..` 越界
- **Koishi 命令**：注册 Koishi 命令并配置回调子流程；也可在有消息会话的事件任务或命令回调中从已注册命令列表选择并直接触发
- **AI 对话与 OCR 兜底**：调用兼容 OpenAI Chat Completions 的 AI 服务；图片 OCR 在 OneBot 接口失败时可选用视觉模型兜底，并将识别结果交给后续 AI 校对、总结、翻译或分类
- **任务编辑器**：
  - 磁贴 **指针拖拽**（桌面鼠标 / 触屏长按 300ms）到画布任意位置，或 **点击** 追加到任务末尾
  - **拖拽添加子磁贴**：长按磁贴拖到父磁贴（如「条件判断」「循环」）上释放即成其子项，带目标高亮、插入指示线与提示徽章
  - 步骤顺序支持 **拖拽排序** 与 **上移/下移**（可跨层级拖动，自动阻止拖入自身子树；多选批量移动）
  - 每步可展开配置参数（必填项前端 + 后端双重校验）
  - 支持步骤 **删除 / 复制 / 禁用启用**，if 判断含「条件规则区 / 成立 / 不成立」，循环含「循环体」
- **条件判断增强**：条件规则区子磁贴内置「取值字段（JSON 路径）」按点路径提取子值比较，并展示该接口全部 JSON 返回字段说明；内置参数帮助文档
- **触发方式**：手动触发、定时触发（cron 表达式）、固定间隔触发、事件触发（群消息 / 私聊消息 / 有人入群 / 有人退群 / 群消息撤回）
- **执行引擎**：顺序执行、分支跳转、循环计数、延时等待、变量读写、代码工具运行；全异步，不阻塞主线程；同一任务防重入，可手动停止
- **调试日志开关**：默认静默（仅显式「日志输出」与错误信息）；开启后逐步输出 进入/退出节点、参数值、中间结果、判断结果、错误信息
- **OneBot 框架适配**：配置可指定 LLOneBot / NapCat 或自动识别，兼容框架间参数与 action 命名差异
- **执行日志**：每条运行记录状态（运行中/成功/失败/已停止）、耗时、逐步骤执行明细，可筛选、展开、清空
- **数据持久化**：任务与日志均存于 Koishi 数据库，日志按保留天数自动清理；任务列表内存缓存 + 前端刷新请求合并，WebUI 响应更快

## 安装

```bash
# 将本插件目录放入 Koishi 工作区后，在插件市场或通过 package.json 依赖安装
npm install koishi-plugin-fully-customized-function-mywl
```

在 Koishi 控制台启用插件，并在左侧导航选择「全自定义功能」进入编排面板。

> 前端资源（dist）由 Koishi 工作区的 `koishi dev/build` 自动构建，无需单独构建。

## 快速上手

1. 打开「任务编排」页，点击 **新建任务**
2. 填写任务名称，选择触发方式（如：定时 `*/10 * * * *` 每 10 分钟）
3. 从左侧磁贴库 **拖拽** 或 **点击** 磁贴搭建流程，如：
   - `发送群聊天消息` → 群号填 `888888`，内容填 `整点自动报时：{now}`
4. 点击 **保存**（校验通过后生效），再点 **立即执行** 试运行
5. 切换「执行日志」页查看每次运行的详细结果

### 条件判断的「取值字段（JSON 路径）」

条件规则区子磁贴（OneBot 查询类 / Koishi 信息类）执行后结果以 JSON 文本存入变量，比较前可用「取值字段」按路径提取子值：

- 路径用 `.` 分层，数组用下标：`member_list.0.user_id`、`current_talkative.nickname`
- 可用键名在磁贴参数区「本磁贴 JSON 返回可用字段」中逐项列出（包含类型 / 含义 / 来源）
- 路径不存在 / 值为空时按**空字符串**处理（`isEmpty` 成立、`== ''` 成立，不报错）
- 取出的值统一转字符串参与比较（数字可宽松相等，`1` 与 `'1'` 相等）
- 「对比值」可直接粘贴 JSON 文本做整体文本相等比较
- 比较运算符支持 **正则匹配（regex）/ 正则不匹配（notRegex）**：对比值填正则表达式（如 `^\d{4,}$`），非法表达式视为不匹配

> **AI 密钥说明**：AI 对话请求与 AI OCR 兜底均仅支持 HTTP(S) 的兼容 Chat Completions 服务；推荐通过任务运行时变量注入密钥，避免直接保存到任务。密钥不会写入执行日志，但直接填写在磁贴参数中时会随任务定义持久化。

> **命令说明**：命令由任务执行时注册，同一条命令只注册一次；插件停用或重启时自动移除。回调中 `{cmdContent}` 为命令后剩余文本，`{cmdArgs}` 为按空格分割的参数 JSON 数组。触发已有命令需要当前消息会话，用于保证命令权限、平台和用户上下文正确。

### AI OCR 兜底配置

当 OneBot 实现不支持 `ocr_image` / `ocr`，或接口调用发生错误时，可在「图片 OCR」磁贴中启用 **AI OCR 兜底**：

1. 图片填写可由视觉 AI 服务访问的公开 `http` / `https` URL；本地路径、OneBot 图片文件名仅能交给 OneBot OCR 处理。
2. 将「AI OCR 兜底」设为“开启”，填写兼容 OpenAI Chat Completions 的服务地址、API 密钥和支持图像输入的视觉模型名。
3. 可按业务调整 OCR 提示词，例如要求保留换行、还原表格或限定识别语言。
4. OneBot OCR 成功时不会请求 AI；仅 OneBot OCR 失败后才执行兜底，避免额外模型调用与费用。

AI 兜底返回结构：

```json
{
  "texts": [{ "text": "识别出的完整文本", "confidence": null, "coordinates": [] }],
  "language": "ai-vision",
  "source": "ai-fallback",
  "model": "实际模型名"
}
```

后续磁贴可通过 `{结果变量}` 引用完整 JSON，或在条件判断中使用 `texts.0.text` 读取识别文本。视觉模型必须支持 Chat Completions 的 `image_url` 消息内容格式。

### 触发已有命令

「触发已有命令」磁贴会从当前 Koishi Commander 实时下发的已注册命令中提供下拉选项；刷新任务页面即可更新列表。若命令由任务运行时动态注册、尚未出现在下拉列表，或需调用未展示的命令，可填写“手动命令名”，它会优先于下拉选择生效。命令参数支持 `{变量名}` 模板替换。

## 触发方式

| 方式 | 配置 | 说明 |
| --- | --- | --- |
| 手动触发 | — | 仅通过 WebUI「立即执行」运行 |
| 定时触发 | cron 表达式 | 5 段格式，详见下方语法 |
| 固定间隔 | 秒数（≥5） | 按固定间隔循环执行 |
| 事件触发 | 事件类型 | 群/私聊消息、入群、退群、撤回时触发，自动注入事件变量 |

### cron 表达式语法

`分 时 日 月 周`，支持 `*`、`?`（同 `*`）、数字、`a-b` 范围、`*/n` 步长、`,` 列表：

- `*/10 * * * *` 每 10 分钟
- `0 8 * * *` 每天 08:00
- `0 9 * * 1` 每周一 09:00
- `30 14 1,15 * *` 每月 1 日与 15 日 14:30

| `{cmdName}` | 自定义命令回调 | 当前被执行的命令名 |
| `{cmdContent}` | 自定义命令回调 | 命令后的完整原始文本参数 |
| `{cmdArgs}` | 自定义命令回调 | 按空格分割后的参数 JSON 数组；带引号的内容会作为同一个参数 |
| 自定义变量 | 全部 | 由「设置变量」磁贴产生；循环变量可用 `{i}` |

## 表达式语法（条件、表达式取值的设置变量）

支持：算术 `+ - * / %`、比较 `== != > < >= <=`、逻辑 `&& || !`、括号、三元 `条件 ? 值1 : 值2`、字符串拼接与比较。

- 变量引用 `{count}` 或裸标识符 `count`（变量已存在时取变量值）
- 未定义的裸单词按字符串字面量处理，如 `{type} == warn`
- 示例：`{atCount} > 3 && {content} != ""`、`count + 1`、`{score} >= 60 ? "通过" : "不通过"`

## 配置项

插件配置保持极简，其余功能均在 WebUI 中操作：

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| 插件总开关 | 开启 | 关闭后调度器与 WebUI 均停用 |
| 日志保留天数 | 7 | 超过该天数的执行日志自动清理 |
| 任务调试日志 | 关闭 | 开启后逐步输出详细日志（进入/退出节点、参数值、中间结果、判断结果、错误信息）；关闭时仅输出「日志输出 / 读取变量」步骤与错误/失败摘要 |
| OneBot 框架适配 | 自动识别 | `auto` 自动检测；也可手动指定 `LLOneBot` / `NapCat`，对参数类型（布尔/JSON 文本）与 action 命名差异做兼容处理 |

## 注意事项

- **权限**：仅管理员可创建 / 修改 / 删除任务；WebUI 入口 `authority = 3`
- WebUI 修改任务或任务运行结束后，所有已打开的客户端会自动同步最新数据，无需手动刷新
- 事件触发的任务请在「事件触发」中选择监听事件；消息事件会自动区分群聊 / 私聊
- 遭撤回/禁用/删除的消息 ID 等接口参数可能失效，接口错误会记录在日志中便于排查
